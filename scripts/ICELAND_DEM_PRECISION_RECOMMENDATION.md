# 冰岛 DEM 精度选择建议

**基于**: 冰岛 F 路场景和系统 DEM 证据需求

## 文件精度对比

根据图片中的文件列表，有以下三种精度可选：

| 精度 | 文件大小 | 适用场景 | 优势 | 劣势 |
|------|---------|---------|------|------|
| **10x10m** | ~3GB | F 路详细地形分析 | 最高精度，适合精确坡度计算 | 文件大，存储和查询成本高 |
| **20x20m** | ~686MB | 平衡选择 | 精度足够，文件适中 | 精度略低于 10m |
| **50x50m** | ~118MB | 概览和快速查询 | 文件小，查询快 | 精度较低，不适合详细分析 |

## 推荐方案

### 🎯 **推荐：20x20m 精度**

**文件**: `IslandsDEMv1.0 20x20m isn2016 zmasl.tif`

**理由**:

1. **精度足够**:
   - 20m 分辨率对于 F 路地形分析足够精确
   - 可以准确计算坡度（百分比）
   - 可以准确计算累计爬升
   - 满足 DEM 证据的所有精度要求

2. **性能平衡**:
   - 文件大小适中（686MB vs 3GB）
   - 查询性能良好
   - 存储成本合理

3. **实际需求匹配**:
   - F 路分析不需要 10m 级别的超高精度
   - 20m 精度已经远高于当前 `geo_dem_global` 的精度
   - 对于路线规划决策，20m 精度完全足够

### 📊 精度对比分析

**当前系统**:
- 使用 `geo_dem_global`（全球 DEM）
- 精度可能为 90m 或 300m（未确认）
- 查询成功但精度较低

**升级到 20x20m**:
- 精度提升 **4.5-15 倍**（相比 90m-300m）
- 文件大小增加 **5.8 倍**（相比 118MB）
- 查询性能影响：**可接受**（PostGIS 栅格查询优化良好）

**升级到 10x10m**:
- 精度提升 **9-30 倍**（相比 90m-300m）
- 文件大小增加 **25.4 倍**（相比 118MB）
- 查询性能影响：**可能较慢**（文件大，查询时间长）

## 坐标系选择

### 推荐：`isn2016`

**文件**: `IslandsDEMv1.0 20x20m isn2016 zmasl.tif`

**理由**:
- ISN2016 是冰岛较新的坐标系标准
- 与系统其他数据兼容性更好
- 精度更高（相比 ISN93）

## 实施建议

### 1. 导入 20x20m DEM 数据

```bash
# 使用 raster2pgsql 导入到 PostGIS
raster2pgsql -s 5327 -I -C -M "IslandsDEMv1.0 20x20m isn2016 zmasl.tif" -F -t 100x100 geo_dem_iceland_20m | psql -d your_database
```

**参数说明**:
- `-s 5327`: ISN2016 坐标系 SRID（需要确认）
- `-I`: 创建空间索引
- `-C`: 应用约束
- `-M`: 更新统计信息
- `-F`: 添加文件名列
- `-t 100x100`: 瓦片大小（100x100 像素）

### 2. 更新查询策略

修改 `DEMElevationService` 的查询优先级：

```typescript
// 1. 优先查询 geo_dem_iceland_20m（冰岛专用高精度）
// 2. 后备查询 geo_dem_cities_merged（城市数据）
// 3. 最终后备 geo_dem_global（全球数据）
```

### 3. 验证精度提升

运行测试脚本验证精度提升：

```bash
npx tsx scripts/test-iceland-dem-direct.ts
```
