# MCP 服务自然语言调用测试 - 快速开始

**测试脚本**: `test-planning-assistant-mcp-natural-language.ts`

---

## 🚀 快速开始

### 1. 启动服务器

```bash
# 方式 1: 开发模式（推荐）
npm run dev

# 方式 2: 后端开发模式
npm run backend:dev
```

等待服务器启动完成（通常需要几秒钟）。

### 2. 运行测试

在**另一个终端**中运行：

```bash
npm run test:planning-assistant-mcp
```

## ⚠️ 常见问题

### 问题 1: 服务器未运行

**错误**: `❌ 服务器未运行！`

**解决方案**:
```bash
# 启动服务器
npm run dev
```

### 问题 2: 某些服务测试失败

**可能原因**:
- 服务需要 API 密钥配置（如 Exa、Amadeus）
- 服务需要 OAuth 认证（如 Rail MCP）
- 服务暂时不可用

**注意**: 只要路由目标正确，测试仍然会通过。服务不可用时会返回友好的错误提示。

### 问题 3: 连接超时

**解决方案**:
- 检查服务器是否正常运行
- 检查端口是否正确（默认 3000）
- 检查防火墙设置
