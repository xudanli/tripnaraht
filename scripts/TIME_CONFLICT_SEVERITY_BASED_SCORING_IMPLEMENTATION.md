### 核心变更

**修改前**（方案A）:
```typescript
// 每个时间冲突扣 18 分（不考虑严重程度）
const conflictPenalty = Math.min(timeConflicts.length * 18, 80);
score -= conflictPenalty;
```

**修改后**（方案C）:
```typescript
// 根据时间冲突数量和严重程度扣分（方案C：差异化扣分）
// HIGH（红线）级别: 每个扣 25 分
// MEDIUM（警告）级别: 每个扣 15 分
// LOW（信息）级别: 每个扣 5 分
// 最大扣分: 90 分
const conflictPenalty = timeConflicts.reduce((sum, conflict) => {
  if (conflict.severity === ConflictSeverity.HIGH) {
    return sum + 25;  // 红线级别，严重问题
  } else if (conflict.severity === ConflictSeverity.MEDIUM) {
    return sum + 15;  // 警告级别，中等问题
  } else {
    return sum + 5;   // 信息级别，轻微问题
  }
}, 0);
const finalPenalty = Math.min(conflictPenalty, 90); // 最多扣90分
score -= finalPenalty;
```

## 📊 扣分规则

### 严重程度对应扣分

| 严重程度 | 每个冲突扣分 | 说明 |
|---------|-------------|------|
| **HIGH**（红线） | 25 分 | 严重问题，必须解决 |
| **MEDIUM**（警告） | 15 分 | 中等问题，建议解决 |
| **LOW**（信息） | 5 分 | 轻微问题，可选解决 |

### 最大扣分限制

- **最大扣分**: 90 分
- **最低分数**: 10 分（100 - 90）
