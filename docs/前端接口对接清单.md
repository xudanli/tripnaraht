## 接口对接准备

### 基础配置

- **API 基础地址**: `http://localhost:3000` (开发环境)
- **API 版本**: 当前版本无版本前缀
- **认证方式**: [待确认] JWT Token / Session
- **请求格式**: JSON (`Content-Type: application/json`)
- **响应格式**: JSON（统一标准响应格式）

### 统一响应格式

```typescript
// 成功响应
{
  "success": true,
  "data": { /* 业务数据 */ },
  "message": "操作成功"
}

// 错误响应
{
  "success": false,
  "error": {
    "code": "ERROR_CODE",
    "message": "错误描述"
  }
}
```

### 开发工具推荐

- **API 文档**: Swagger UI (通常位于 `/api/docs`)
- **接口测试**: Postman / Insomnia / Thunder Client
- **类型生成**: 可使用 OpenAPI Generator 生成 TypeScript 类型定义
