# 邮箱验证码注册与登录接口文档

本文档包含邮箱验证码注册和登录功能的详细接口文档，用于前端对接使用。

**接口列表**:
1. 发送邮箱验证码 - POST `/auth/email/send-code`
2. 邮箱验证码注册 - POST `/auth/email/register`
3. 邮箱验证码登录 - POST `/auth/email/login`

---

## 接口 1: 发送邮箱验证码

**接口地址**: `POST /api/auth/email/send-code`

**注意**: 后端已设置全局前缀 `/api`，所有接口路径都以 `/api` 开头。

**接口描述**: 向指定邮箱地址发送6位数字验证码，用于用户注册。验证码有效期为10分钟，1分钟内不能重复发送。

**请求头**:
```
Content-Type: application/json
```

**注意**: 此接口为公开接口，无需认证。

**请求体**:

```json
{
  "email": "user@example.com"
}
```

**参数说明**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `email` | string | 是 | 邮箱地址，必须是有效的邮箱格式 |

**成功响应** (200):

```json
{
  "message": "验证码已发送，请查收邮件"
}
```

**响应字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| `message` | string | 成功提示信息 |

**错误响应** (400):

```json
{
  "statusCode": 400,
  "message": "无效的邮箱地址",
  "error": "Bad Request"
}
```

或

```json
{
  "statusCode": 400,
  "message": "验证码发送过于频繁，请稍后再试",
  "error": "Bad Request"
}
```

**常见错误码**:

| 错误信息 | HTTP状态码 | 说明 |
|---------|-----------|------|
| `无效的邮箱地址` | 400 | 邮箱格式不正确 |
| `验证码发送过于频繁，请稍后再试` | 400 | 1分钟内已发送过验证码 |
| `发送验证码失败，请稍后再试` | 400 | SMTP服务异常，无法发送邮件 |

**前端对接要点**:

1. **表单验证**:
   - 邮箱格式验证（前端先验证，减少无效请求）
   - 使用正则表达式：`/^[^\s@]+@[^\s@]+\.[^\s@]+$/`
   - 显示友好的错误提示

2. **用户体验**:
   - 发送成功后显示倒计时（60秒）
   - 倒计时期间禁用"发送验证码"按钮
   - 显示"验证码已发送，请查收邮件"提示
   - 提示用户检查垃圾邮件文件夹

3. **防刷机制**:
   - 前端配合后端防刷：1分钟内禁用发送按钮
   - 显示剩余等待时间
   - 避免用户频繁点击

4. **错误处理**:
   - 显示具体的错误信息（从 `message` 获取）
   - 网络错误时提示"网络异常，请检查网络连接"
   - SMTP错误时提示"邮件服务暂时不可用，请稍后重试"

5. **Loading 状态**:
   - 发送时显示加载状态
   - 禁用发送按钮防止重复提交

**TypeScript 类型定义**:


**前端调用示例**:

```typescript
// 使用 axios
import axios from 'axios';

async function sendVerificationCode(email: string): Promise<void> {
  try {
    const response = await axios.post<SendVerificationCodeResponse>(
      '/auth/email/send-code',
      { email },
      {
        headers: {
          'Content-Type': 'application/json',
        },
      }
    );
    
    // 发送成功
    showSuccessMessage(response.data.message);
    startCountdown(60); // 开始60秒倒计时
  } catch (error) {
    if (axios.isAxiosError(error)) {
      if (error.response) {
        // 服务器返回错误
        const errorMessage = error.response.data?.message || '发送验证码失败';
        showErrorMessage(errorMessage);
      } else {
        // 网络错误
        showErrorMessage('网络异常，请检查网络连接');
      }
    } else {
      showErrorMessage('发送验证码失败，请稍后重试');
    }
  }
}

// 在组件中使用
const RegisterPage = () => {
  const [email, setEmail] = useState('');
  const [countdown, setCountdown] = useState(0);
  const [loading, setLoading] = useState(false);
  
  // 倒计时逻辑
  useEffect(() => {
    if (countdown > 0) {
      const timer = setTimeout(() => setCountdown(countdown - 1), 1000);
      return () => clearTimeout(timer);
    }
  }, [countdown]);
  
  const handleSendCode = async () => {
    // 前端邮箱格式验证
    const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
    if (!emailRegex.test(email)) {
      showErrorMessage('请输入有效的邮箱地址');
      return;
    }
    
    setLoading(true);
    try {
      await sendVerificationCode(email);
    } finally {
      setLoading(false);
    }
  };
  
  return (
    <div>
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        placeholder="请输入邮箱地址"
      />
      <button
        onClick={handleSendCode}
        disabled={loading || countdown > 0}
      >
        {countdown > 0 ? `重新发送(${countdown}s)` : '发送验证码'}
      </button>
    </div>
  );
};
```

## 接口 2: 邮箱验证码注册

**接口地址**: `POST /api/auth/email/register`

**注意**: 后端已设置全局前缀 `/api`，所有接口路径都以 `/api` 开头。

**接口描述**: 使用邮箱和验证码注册新用户。验证码验证成功后，系统会自动创建用户账号并返回访问令牌。注册成功后，用户自动登录。

**请求头**:
```
Content-Type: application/json
```

**注意**: 此接口为公开接口，无需认证。

**请求体**:

```json
{
  "email": "user@example.com",
  "code": "123456",
  "displayName": "John Doe"
}
```

**参数说明**:

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `email` | string | 是 | 邮箱地址，必须与发送验证码时使用的邮箱一致 |
| `code` | string | 是 | 6位数字验证码 |
| `displayName` | string | 否 | 用户显示名称，可选 |

**成功响应** (200):

```json
{
  "user": {
    "id": "f3626ff1-7a9b-46d9-8b8b-7f53a14583b1",
    "email": "user@example.com",
    "displayName": "John Doe",
    "avatarUrl": null,
    "emailVerified": true
  },
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

**响应字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| `user` | object | 用户信息 |
| `user.id` | string | 用户ID（UUID） |
| `user.email` | string | 邮箱地址 |
| `user.displayName` | string \| null | 用户显示名称 |
| `user.avatarUrl` | string \| null | 用户头像URL |
| `user.emailVerified` | boolean | 邮箱是否已验证（注册时自动为true） |
| `accessToken` | string | 访问令牌（JWT），用于后续API请求认证 |

**Cookie 说明**:

注册成功后，服务器会自动设置 `refresh_token` cookie（httpOnly），用于刷新访问令牌。

**错误响应** (400):

```json
{
  "statusCode": 400,
  "message": "验证码无效或已过期",
  "error": "Bad Request"
}
```

或

```json
{
  "statusCode": 400,
  "message": "该邮箱已被注册",
  "error": "Bad Request"
}
```

**常见错误码**:

| 错误信息 | HTTP状态码 | 说明 |
|---------|-----------|------|
| `验证码无效或已过期` | 400 | 验证码错误、已使用或已过期 |
| `该邮箱已被注册` | 400 | 邮箱已被其他用户注册 |
| `无效的邮箱地址` | 400 | 邮箱格式不正确 |
| `注册失败: {具体错误}` | 400 | 其他注册失败原因 |

**前端对接要点**:

1. **表单验证**:
   - 邮箱格式验证
   - 验证码格式验证（6位数字）
   - 验证码不能为空
   - 显示名称可选，但如果有值，建议限制长度（如50字符）

2. **用户体验**:
   - 注册成功后自动保存 `accessToken`（建议存储在内存或 sessionStorage）
   - 自动跳转到首页或用户中心
   - 显示注册成功提示
   - 保存用户信息到全局状态（如 Redux、Zustand 等）

3. **Token 管理**:
   - 将 `accessToken` 存储在内存或 sessionStorage（不要存储在 localStorage，更安全）
   - 在后续API请求的请求头中添加：`Authorization: Bearer {accessToken}`
   - 实现自动刷新token机制（当accessToken过期时，使用refresh_token刷新）

4. **错误处理**:
   - 验证码错误时，提示"验证码错误，请重新输入"
   - 验证码过期时，提示"验证码已过期，请重新获取"
   - 邮箱已注册时，提示"该邮箱已被注册，请直接登录"
   - 提供"重新发送验证码"的快捷链接

5. **Loading 状态**:
   - 提交时显示加载状态
   - 禁用提交按钮防止重复提交

6. **安全性**:
   - 不要在URL中传递token
   - 使用HTTPS传输（生产环境）
   - 定期刷新token

**前端调用示例**:

```typescript
// 使用 axios
import axios from 'axios';
import { useRouter } from 'next/router';
import { useAuthStore } from '@/stores/auth'; // 假设使用 Zustand

async function registerWithEmail(
  email: string,
  code: string,
  displayName?: string
): Promise<RegisterWithEmailResponse> {
  try {
    const response = await axios.post<RegisterWithEmailResponse>(
      '/auth/email/register',
      { email, code, displayName },
      {
        headers: {
          'Content-Type': 'application/json',
        },
        withCredentials: true, // 重要：包含 cookies（用于 refresh_token）
      }
    );
    
    return response.data;
  } catch (error) {
    if (axios.isAxiosError(error)) {
      if (error.response) {
        const errorMessage = error.response.data?.message || '注册失败';
        throw new Error(errorMessage);
      } else {
        throw new Error('网络异常，请检查网络连接');
      }
    }
    throw error;
  }
}

// 在组件中使用
const RegisterForm = () => {
  const router = useRouter();
  const { setUser, setAccessToken } = useAuthStore();
  const [email, setEmail] = useState('');
  const [code, setCode] = useState('');
  const [displayName, setDisplayName] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');
  
  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setError('');
    setLoading(true);
    
    try {
      // 前端验证
      if (!email || !code) {
        setError('请填写邮箱和验证码');
        setLoading(false);
        return;
      }
      
      const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
      if (!emailRegex.test(email)) {
        setError('请输入有效的邮箱地址');
        setLoading(false);
        return;
      }
      
      if (!/^\d{6}$/.test(code)) {
        setError('验证码必须是6位数字');
        setLoading(false);
        return;
      }
      
      // 调用注册接口
      const result = await registerWithEmail(email, code, displayName);
      
      // 保存用户信息和token
      setUser(result.user);
      setAccessToken(result.accessToken);
      
      // 保存token到sessionStorage（可选，也可以只存在内存中）
      sessionStorage.setItem('accessToken', result.accessToken);
      
      // 显示成功提示
      showSuccessMessage('注册成功！');
      
      // 跳转到首页
      router.push('/');
    } catch (error: any) {
      const errorMessage = error.message || '注册失败，请稍后重试';
      setError(errorMessage);
      
      // 根据错误类型提供不同提示
      if (errorMessage.includes('验证码')) {
        // 验证码相关错误，提供重新发送的选项
        showErrorMessage(errorMessage + '，请重新获取验证码');
      } else if (errorMessage.includes('已被注册')) {
        // 邮箱已注册，提示登录
        showErrorMessage(errorMessage + '，请直接登录');
        setTimeout(() => router.push('/login'), 2000);
      } else {
        showErrorMessage(errorMessage);
      }
    } finally {
      setLoading(false);
    }
  };
  
  return (
    <form onSubmit={handleSubmit}>
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        placeholder="邮箱地址"
        required
      />
      <input
        type="text"
        value={code}
        onChange={(e) => setCode(e.target.value)}
        placeholder="验证码（6位数字）"
        maxLength={6}
        required
      />
      <input
        type="text"
        value={displayName}
        onChange={(e) => setDisplayName(e.target.value)}
        placeholder="显示名称（可选）"
        maxLength={50}
      />
      {error && <div className="error">{error}</div>}
      <button type="submit" disabled={loading}>
        {loading ? '注册中...' : '注册'}
      </button>
    </form>
  );
};
```

**Token 使用示例**:

```typescript
// 配置 axios 拦截器，自动添加 token
import axios from 'axios';

const apiClient = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_BASE_URL,
  withCredentials: true, // 包含 cookies
});

// 请求拦截器：自动添加 accessToken
apiClient.interceptors.request.use((config) => {
  const accessToken = sessionStorage.getItem('accessToken');
  if (accessToken) {
    config.headers.Authorization = `Bearer ${accessToken}`;
  }
  return config;
});

// 响应拦截器：处理 token 过期
apiClient.interceptors.response.use(
  (response) => response,
  async (error) => {
    if (error.response?.status === 401) {
      // Token 过期，尝试刷新
      try {
        const refreshResponse = await axios.post('/auth/refresh', {}, {
          withCredentials: true,
        });
        const newAccessToken = refreshResponse.data.accessToken;
        sessionStorage.setItem('accessToken', newAccessToken);
        
        // 重试原请求
        error.config.headers.Authorization = `Bearer ${newAccessToken}`;
        return apiClient.request(error.config);
      } catch (refreshError) {
        // 刷新失败，跳转到登录页
        sessionStorage.removeItem('accessToken');
        window.location.href = '/login';
        return Promise.reject(refreshError);
      }
    }
    return Promise.reject(error);
  }
);
```

## 完整注册流程示例

```typescript
// 完整的注册流程
const CompleteRegisterFlow = () => {
  const [step, setStep] = useState<'email' | 'code' | 'success'>('email');
  const [email, setEmail] = useState('');
  const [code, setCode] = useState('');
  const [countdown, setCountdown] = useState(0);
  
  // 步骤1: 输入邮箱并发送验证码
  const handleSendCode = async () => {
    try {
      await sendVerificationCode(email);
      setStep('code');
      setCountdown(60);
    } catch (error) {
      // 错误处理
    }
  };
  
  // 步骤2: 输入验证码并注册
  const handleRegister = async () => {
    try {
      const result = await registerWithEmail(email, code);
      // 保存用户信息和token
      setUser(result.user);
      setAccessToken(result.accessToken);
      setStep('success');
    } catch (error) {
      // 错误处理
    }
  };
  
  return (
    <div>
      {step === 'email' && (
        <EmailStep
          email={email}
          onChange={setEmail}
          onSubmit={handleSendCode}
        />
      )}
      {step === 'code' && (
        <CodeStep
          code={code}
          onChange={setCode}
          onSubmit={handleRegister}
          countdown={countdown}
          onResend={handleSendCode}
        />
      )}
      {step === 'success' && (
        <SuccessStep onContinue={() => router.push('/')} />
      )}
    </div>
  );
};
```

   - 提供"重新发送验证码"的快捷链接

5. **Loading 状态**:
   - 提交时显示加载状态
   - 禁用提交按钮防止重复提交

6. **安全性**:
   - 不要在URL中传递token
   - 使用HTTPS传输（生产环境）
   - 定期刷新token

```typescript
// 使用 axios
import axios from 'axios';
import { useRouter } from 'next/router';
import { useAuthStore } from '@/stores/auth'; // 假设使用 Zustand

async function loginWithEmail(
  email: string,
  code: string
): Promise<LoginWithEmailResponse> {
  try {
    const response = await axios.post<LoginWithEmailResponse>(
      '/auth/email/login',
      { email, code },
      {
        headers: {
          'Content-Type': 'application/json',
        },
        withCredentials: true, // 重要：包含 cookies（用于 refresh_token）
      }
    );
    
    return response.data;
  } catch (error) {
    if (axios.isAxiosError(error)) {
      if (error.response) {
        const errorMessage = error.response.data?.message || '登录失败';
        throw new Error(errorMessage);
      } else {
        throw new Error('网络异常，请检查网络连接');
      }
    }
    throw error;
  }
}

// 在组件中使用
const LoginForm = () => {
  const router = useRouter();
  const { setUser, setAccessToken } = useAuthStore();
  const [email, setEmail] = useState('');
  const [code, setCode] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');
  
  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setError('');
    setLoading(true);
    
    try {
      // 前端验证
      if (!email || !code) {
        setError('请填写邮箱和验证码');
        setLoading(false);
        return;
      }
      
      const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
      if (!emailRegex.test(email)) {
        setError('请输入有效的邮箱地址');
        setLoading(false);
        return;
      }
      
      if (!/^\d{6}$/.test(code)) {
        setError('验证码必须是6位数字');
        setLoading(false);
        return;
      }
      
      // 调用登录接口
      const result = await loginWithEmail(email, code);
      
      // 保存用户信息和token
      setUser(result.user);
      setAccessToken(result.accessToken);
      
      // 保存token到sessionStorage（可选，也可以只存在内存中）
      sessionStorage.setItem('accessToken', result.accessToken);
      
      // 显示成功提示
      showSuccessMessage('登录成功！');
      
      // 跳转到首页
      router.push('/');
    } catch (error: any) {
      const errorMessage = error.message || '登录失败，请稍后重试';
      setError(errorMessage);
      
      // 根据错误类型提供不同提示
      if (errorMessage.includes('验证码')) {
        // 验证码相关错误，提供重新发送的选项
        showErrorMessage(errorMessage + '，请重新获取验证码');
      } else if (errorMessage.includes('未注册')) {
        // 邮箱未注册，提示注册
        showErrorMessage(errorMessage + '，请先注册');
        setTimeout(() => router.push('/register'), 2000);
      } else {
        showErrorMessage(errorMessage);
      }
    } finally {
      setLoading(false);
    }
  };
  
  return (
    <form onSubmit={handleSubmit}>
      <input
        type="email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        placeholder="邮箱地址"
        required
      />
      <input
        type="text"
        value={code}
        onChange={(e) => setCode(e.target.value)}
        placeholder="验证码（6位数字）"
        maxLength={6}
        required
      />
      {error && <div className="error">{error}</div>}
      <button type="submit" disabled={loading}>
        {loading ? '登录中...' : '登录'}
      </button>
    </form>
  );
};
```

## 注意事项

1. **邮箱验证码有效期**: 10分钟
2. **防刷机制**: 1分钟内不能重复发送验证码
3. **验证码格式**: 6位数字
4. **Token 存储**: 建议使用 sessionStorage 或内存存储，不要使用 localStorage
5. **Cookie 设置**: refresh_token 会自动通过 httpOnly cookie 设置，前端无需手动处理
6. **HTTPS**: 生产环境必须使用 HTTPS
7. **错误处理**: 所有错误都会返回明确的错误信息，前端应友好展示
