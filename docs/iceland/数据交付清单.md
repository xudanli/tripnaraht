### 6. 决策支持数据

#### [decision-support/rhythm-patterns.json](decision-support/rhythm-patterns.json)
- **内容**: 路线节奏模式定义系统（TripNARA核心理论）
- **理论框架**:
  - 三维度：pace（速度）、intensity_variation（强度变化）、recovery_time（恢复时间）
- **6种节奏模式**:
  1. **轻松观光节奏** - 低强度一致性，适合初次旅行、放松休息
  2. **风景巡礼节奏** - 中强度渐进性，适合深度体验、摄影爱好者
  3. **探险挑战节奏** - 高强度剧烈性，适合寻求刺激、挑战自我
  4. **文化沉浸节奏** - 低强度渐进性，适合文化体验、慢旅行
  5. **摄影追逐节奏** - 中高强度剧烈性，适合摄影师、追求完美构图
  6. **家庭友好节奏** - 低强度一致性，适合带儿童老人、安全优先
- **每种节奏包含**:
  - 详细特征描述
  - 日常节奏曲线
  - 情绪历程
  - 适合人群和状态
  - 节奏指标
  - 示例路线
- **匹配框架**: 用户状态→节奏模式匹配规则
- **数据来源**: TripNARA产品理论、用户研究、旅行心理学
- **可信度**: 0.92
- **文件大小**: ~42KB

## 🎯 核心亮点

### 1. 完全符合TripNARA产品哲学

✅ **判断而非规划** - 所有数据围绕"这条路线值得走吗？"设计
✅ **可信性优先** - 所有数据有明确来源和可信度评分
✅ **可解释性** - 风险评分有详细计算公式，每个判断都有理由
✅ **不确定性透明** - 概率和严重性都有明确量化

### 2. 决策型数据结构

每条路线都包含完整的**决策支持数据**：
- **决策因素分析**: 体能、心理、时间、不确定性、社交5个维度
- **节奏匹配**: 与6种节奏模式的匹配分析
- **风险评估**: 多维度风险分解和缓解策略
- **用户反馈**: 真实用户的经验和建议
- **决策问题**: "应该去吗？"的具体判断框架

### 3. 安全优先

- 雷尼斯黑沙滩的**致命危险详细说明**（潜行波历史事件）
- 6种天气风险的**完整应急措施**
- 每个景点的**具体安全警告**
- 应急联系方式和实时数据源

### 4. 节奏模式系统（创新亮点）

- **TripNARA独创的节奏理论**，定义了路线的"呼吸"方式
- 6种节奏模式涵盖从轻松到挑战的全部旅行状态
