- **内容**:
  - 可行性评分理论框架（6维度加权评分系统）
  - 核心理念:"可行性 ≠ 推荐度，而是'能否成功完成'的概率"
  - 6个评估维度详细定义：
    1. 时间可行性（weight: 0.25）- 用户时间是否足够
    2. 季节可行性（weight: 0.20）- 当前季节是否适合
    3. 经验匹配度（weight: 0.20）- 用户经验是否匹配路线难度
    4. 装备可行性（weight: 0.15）- 是否有必需装备（四驱车、冬季轮胎等）
    5. 预算可行性（weight: 0.10）- 预算是否支持成本
    6. 风险容忍度匹配（weight: 0.10）- 用户风险承受能力

2. 使用 [golden-circle.json](routes/golden-circle.json) 作为路线数据模板

4. 所有数据遵循 JSON Schema 验证

3. 验证数据源链接的有效性
4. 确认更新频率符合要求
