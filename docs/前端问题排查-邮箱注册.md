# 前端发送验证码失败 - 问题排查与解决

**问题**: 前端发送验证码返回 500 Internal Server Error  
**解决时间**: 2024-12-30  
**状态**: ✅ 已解决

---

## 🔍 问题分析

### 错误现象
- **前端请求**: `POST http://localhost:5174/api/auth/email/send-code`
- **HTTP 状态码**: 500 Internal Server Error
- **错误信息**: "发送验证码失败,请稍后重试"

### 根本原因
前端请求路径是 `/api/auth/email/send-code`，但后端接口路径是 `/auth/email/send-code`（缺少 `/api` 前缀），导致路由不匹配。

---

## ✅ 解决方案

### 1. 后端添加全局前缀

在 `src/main.ts` 中添加全局 API 前缀：

```typescript
async function bootstrap() {
  const app = await NestFactory.create(AppModule);
  
  // 设置全局 API 前缀
  app.setGlobalPrefix('api');
  
  // ... 其他配置
}
```

### 2. 更新 Swagger 文档路径

为避免与 API 路径冲突，将 Swagger UI 路径从 `/api` 改为 `/api-docs`：

```typescript
SwaggerModule.setup('api-docs', app, document, {
  // ...
});
```

## 🔧 前端需要做的修改

### 1. 更新 API 基础路径

如果前端使用了代理配置，确保代理正确：

```typescript
// 方式1: 使用完整路径
const API_BASE_URL = 'http://localhost:3000';
const response = await axios.post(
  `${API_BASE_URL}/api/auth/email/send-code`,
  { email }
);
```

### 2. 检查代理配置（Vite 示例）

如果使用 Vite，检查 `vite.config.ts`:

```typescript
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:3000',
        changeOrigin: true,
      },
    },
  },
});
```

### 3. 检查代理配置（Next.js 示例）

如果使用 Next.js，检查 `next.config.js`:

```javascript
module.exports = {
  async rewrites() {
    return [
      {
        source: '/api/:path*',
        destination: 'http://localhost:3000/api/:path*',
      },
    ];
  },
};
```

## ✅ 验证步骤

```bash
curl -X POST http://localhost:3000/api/auth/email/send-code \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com"}'
```

**预期响应**:
```json

}
```

### 2. 检查前端网络请求

在浏览器开发者工具的 Network 标签中：
- 确认请求 URL 是 `http://localhost:3000/api/auth/email/send-code`（或通过代理）
- 确认请求方法为 `POST`
- 确认请求头包含 `Content-Type: application/json`
- 确认请求体包含 `{"email":"xxx@example.com"}`

### 3. 检查 CORS 配置

如果直接请求（不使用代理），确认：
- 后端 CORS 配置允许前端域名
- 请求包含正确的 `Origin` 头

## 🐛 常见问题

### 问题 1: 404 Not Found

**原因**: 请求路径不正确  
**解决**: 确认路径包含 `/api` 前缀

### 问题 2: 500 Internal Server Error

**可能原因**:
1. SMTP 配置未正确设置
2. 数据库连接问题
3. 服务端代码错误

**排查步骤**:
1. 检查后端服务日志
2. 检查 SMTP 配置
3. 检查数据库连接

### 问题 3: CORS 错误

**原因**: 前端域名未在 CORS 白名单中  
**解决**: 
- 开发环境：后端会自动允许 localhost
- 生产环境：配置 `FRONTEND_URL` 环境变量
