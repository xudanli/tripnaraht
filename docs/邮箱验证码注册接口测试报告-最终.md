## 🐛 已修复的问题

1. **JWT Token 生成错误** ✅
   - **问题**: `Bad "options.expiresIn" option the payload already has an "exp" property.`
   - **原因**: 手动设置 `exp` 字段与 `signAsync` 的 `expiresIn` 选项冲突
   - **修复**: 移除手动 `exp` 设置，使用 `expiresIn` 选项

2. **数据库表缺失** ✅
   - **问题**: `The table public.email_verification_codes does not exist`
   - **修复**: 使用 `prisma db push` 创建表

3. **SMTP From 字段格式错误** ✅
   - **问题**: `Invalid 'from' field. The email address needs to follow the 'email@example.com' format.`
   - **原因**: Resend 要求 `from` 字段必须是有效的邮箱格式
   - **修复**: 改进 `from` 字段的构造逻辑，确保格式正确

4. **SMTP 配置支持** ✅
   - **新增**: 支持 `SMTP_PASS` 环境变量（除了 `SMTP_PASSWORD`）
   - **新增**: 支持 `SMTP_SECURE` 环境变量
   - **改进**: 更详细的配置日志输出

## 🚀 完整测试流程

### 1. 发送验证码

```bash
curl -X POST http://localhost:3000/api/auth/email/send-code \
  -H "Content-Type: application/json" \
  -d '{"email": "your-email@example.com"}'
```

**预期响应**:
```json
{
  "message": "验证码已发送，请查收邮件"
}
```

### 2. 检查邮箱获取验证码

- 登录邮箱查看验证码邮件
- 验证码是 6 位数字
- 有效期为 10 分钟

### 3. 使用验证码注册

```bash
curl -X POST http://localhost:3000/api/auth/email/register \
  -H "Content-Type: application/json" \
  -d '{
    "email": "your-email@example.com",
    "code": "123456",
    "displayName": "Your Name"
  }' \
  -c cookies.txt
```

**预期响应**:
```json
{
  "user": {
    "id": "uuid",
    "email": "your-email@example.com",
    "displayName": "Your Name",
    "avatarUrl": null,
    "emailVerified": true
  },
  "accessToken": "eyJhbGci..."
}
```

**Cookie**: `refresh_token` 会自动设置

## 🔒 安全特性

1. **验证码有效期**: 10 分钟
2. **防刷机制**: 1 分钟内不能重复发送
3. **验证码一次性使用**: 验证后自动标记为已使用
4. **邮箱唯一性**: 每个邮箱只能注册一次
5. **JWT Token 过期**: 15 分钟（可配置）
6. **Refresh Token 过期**: 30 天（可配置）
7. **Token 旋转**: 每次刷新都会生成新的 refresh token
