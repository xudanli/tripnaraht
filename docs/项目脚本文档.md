## 使用说明

### 运行脚本

大多数脚本通过 npm 命令运行：

```bash
npm run <command> [-- <args>]
```

例如：
```bash
npm run import:nepal-poi -- --all
npm run derive:place-fields -- --address
npm run generate:namecn -- --cityId 123 --limit 50
npm run update:place-address -- --cityId 123 --limit 50
```

### 直接运行脚本

某些脚本可以直接运行：

```bash
ts-node --project tsconfig.backend.json scripts/<script-name>.ts
```

或使用 npx tsx：

```bash
npx tsx scripts/<script-name>.ts
```

### 环境变量

许多脚本需要配置环境变量，请确保 `.env` 文件已正确配置：

- `DATABASE_URL` - 数据库连接字符串
- `OPENAI_API_KEY` - OpenAI API Key（用于 embedding）
- `HUGGINGFACE_API_KEY` - Hugging Face API Key（用于 embedding）
- `DEEPSEEK_API_KEY` - DeepSeek API Key（用于 nameCN 生成）
- `DEEPSEEK_BASE_URL` - DeepSeek API Base URL（可选，默认：https://api.deepseek.com/v1）
- 其他服务相关的 API Key

### 常用脚本详细说明

#### generate:namecn - 根据 nameEN 生成 nameCN

使用 DeepSeek API 将 Place 表的英文名称翻译成中文名称。

**功能特点：**
- 支持按 cityId 过滤处理
- 支持预览模式（dry-run）
- 批量处理，自动处理 API 限流
- 支持断点续传

**使用方法：**
```bash
# 处理所有符合条件的 Place
npm run generate:namecn -- --all

# 只处理指定 cityId 的 Place
npm run generate:namecn -- --cityId 123

# 限制处理数量
npm run generate:namecn -- --limit 100

# 预览模式（不实际更新数据库）
npm run generate:namecn -- --dry-run

# 组合使用
npm run generate:namecn -- --cityId 123 --limit 50 --dry-run
```

**配置要求：**
- `DEEPSEEK_API_KEY` - DeepSeek API Key（必需）
- `DEEPSEEK_BASE_URL` - DeepSeek API Base URL（可选）

**处理逻辑：**
1. 查找有 `nameEN` 但没有 `nameCN` 或 `nameCN` 等于 `nameEN` 的 Place
2. 如果指定了 `--cityId`，只处理该城市的 Place
3. 使用 DeepSeek API 翻译英文名称
4. 更新数据库中的 `nameCN` 字段

#### update:place-address - 更新 Place 的 address 字段（包含中英文名称）

根据 Place 表的 nameCN、nameEN、cityId、location 等信息构建包含中英文名称的地址。

**功能特点：**
- 地址格式包含中英文名称：`{nameCN} / {nameEN}, {cityNameCN} / {cityNameEN}`
- 支持按 cityId 过滤处理
- 支持预览模式（dry-run）
- 支持强制更新已有 address 的 Place
- 批量处理，自动跳过未变化的地址

**使用方法：**
```bash
# 处理所有符合条件的 Place
npm run update:place-address -- --all

# 只处理指定 cityId 的 Place
npm run update:place-address -- --cityId 123

# 限制处理数量
npm run update:place-address -- --limit 100

# 预览模式（不实际更新数据库）
npm run update:place-address -- --dry-run

# 强制更新已有 address 的 Place
npm run update:place-address -- --force

# 组合使用
npm run update:place-address -- --cityId 123 --limit 50 --dry-run
npm run update:place-address -- --force --cityId 123
```

**地址构建逻辑：**
1. 地点名称：`{nameCN} / {nameEN}`（如果都有）
2. 城市名称：`{cityNameCN} / {cityNameEN}`（如果都有且不同）
3. 从 metadata.rawTags 提取街道、区域等信息
4. 如果没有详细地址但有坐标，添加坐标信息

**处理逻辑：**
1. 查找 address 为空、为空字符串或格式不包含 `/` 的 Place（默认）
2. 如果指定了 `--cityId`，只处理该城市的 Place
3. 如果使用 `--force`，会更新所有 Place 的 address
4. 自动跳过地址未变化的 Place
5. 批量更新数据库中的 `address` 字段

## 注意事项

1. **数据导入前备份**：运行数据导入脚本前，建议先备份数据库
2. **API 限流**：爬取脚本已包含延迟机制，但仍需注意 API 限流
3. **环境配置**：确保 `.env` 文件配置正确
4. **依赖安装**：运行前确保已安装所有依赖 `npm install`
5. **数据库连接**：确保数据库服务正在运行
