# Skill: Temporal_Constraint_Optimizer (时间约束与动线优化器)

## Description

专门负责审计和重排初始旅行计划的时间轴。强制执行人类作息常识、POI 营业时间边界以及合理的物理转移缓冲，杜绝反常识调度（如凌晨 1 点安排常规景点），并根据出行人群的体力特征动态调整节奏。

**项目实现位置**：
- 运行时 Skill：`src/skills/itinerary/temporal-constraint-optimizer.skill.ts` — `itinerary.temporalOptimize`
- 确定性优化器：`src/skills/itinerary/temporal-constraint-optimizer.util.ts`
- 编排位置：`itinerary.generate` → **`itinerary.temporalOptimize`** → `itinerary.smart_update`

## Inputs

1. `raw_itinerary` / `itinerary`：待优化的原始行程列表（包含建议时间戳）。
2. `poi_constraints`：涉及地点的已知营业时间（若未知则采用缺省值）。
3. `party_profile`：出行队伍特征（如：是否包含老人/儿童，以决定行程强度）。
4. `environment_context`：目的地特殊环境（如：极光季的极夜、高纬度地区的超长日照）。

## Core Rules (约束条件)

### 1. 绝对时间禁区 (Hard Boundaries)

- **睡眠锁定期**：默认 `23:00` 至次日 `08:00` 为严格休息时间，期间禁止安排任何活动。
- **例外豁免 (Override)**：仅当活动带有特殊环境标签（如 `[极光/星空]`、`[午夜航班]`、`[跨年/夜市]`）时，允许在锁定期间分配时间。

### 2. 餐饮锚点 (Meal Anchors)

- 必须在时间轴上预留独立的就餐区块：
  - 午餐：`11:30 - 13:30` 区间内，分配 1~1.5 小时。
  - 晚餐：`18:00 - 20:00` 区间内，分配 1~2 小时。

### 3. 节奏与缓冲 (Pacing & Buffers)

- **动态位移时间**：任意两个不同地点之间，必须留出至少 `30分钟基础缓冲 + 预估交通时间`。
- **疲劳度控制**：若 `party_profile` 包含低体力人群（老人/小孩），单日核心活动时间（剥离餐饮和休息）不得超过 6 小时，且下午必须强制插入 45-60 分钟的 [Tea Break/休息] 节点。

## Execution Steps (执行逻辑)

1. **冲突扫描 (Audit)**：遍历 `raw_itinerary`，圈出所有落入「睡眠锁定期」、缺乏交通缓冲、或营业时间冲突的节点。
2. **时间轴重排 (Re-schedule)**：
   - 将违规的深夜活动顺延至次日可用时间块。
   - 若单日时间块耗尽（Overbooked），将优先级最低的非核心 POI 移入 `overflow_queue`（备选池），不强行塞入当天。
3. **输出标准化 (Output)**：返回清洗后的带时间戳行程单，并附带一个 `Changelog`（简述：因时间冲突移除了哪些地点，或调整了哪些顺序）。

## 接入建议

- **工作流位置**：将此 Skill 挂载在主规划 Agent 之后。主 Agent 负责「发散选点」（只管选拔最优解，不强求时间完美），然后将草稿 Throw 给具备此 Skill 的校验 Agent 进行「收敛排期」。
- **特殊场景的扩展性**：本 Skill 留出了 `environment_context` 输入口。未来在处理像冰岛、斯瓦尔巴群岛这类高纬度或极端环境的路线时，可以直接通过注入日照数据来动态调整「绝对时间禁区」，而不需要修改底层逻辑。
- **闭环反馈 (ReAct)**：如果重排后发现某一天删减了太多重要景点，Skill 可以返回 `needs_regeneration`，触发主规划 Agent 重新生成一个为期更长（比如 3 天变 4 天）的全新方案。

## 输出要求

必须提供：
- `itinerary`：优化后的行程
- `changelog`：调整记录
- `overflow_queue`：无法排入当日的备选 POI
- `issues`：审计发现的问题列表
- `needs_regeneration`（可选）：建议延长行程的信号

[限制条件]

- 不允许在 23:00-08:00 安排常规 POI（无豁免标签时）
- 不允许省略午餐/晚餐锚点
- 不允许输出 ISO UTC 时间戳作为最终展示时间（统一输出 `HH:mm` 本地时刻）
