# Travel ETA — 前端证据（规划 + 执行）

**阶段：** 可展示规划原因与本段执行结果；**禁止**展示模型有效性话术。

---

## 1. 规划证据（为什么建议预留这么久？）

数据：`segments[].userEvidence` / `Trip.metadata.travelEtaUserEvidenceByToItemId`

### 普通道路

```text
基础车程 2小时15分
建议按 2小时20分安排
预计路况较稳定
```

### 高地 F 路

```text
基础车程 2小时46分
建议预留 3小时36分
额外预留 50分钟

原因：
· 高地 F 路
· 非铺装道路
· 行驶时间不确定性较高
```

### 阻断

```text
当前路线不可执行
该路段要求四驱车型
当前车辆不符合通行条件
```

禁止把 CLOSED / 2WD 渲染成「车程较长」。

---

## 2. 执行结果证据（这次实际用了多久？）

来自 `SegmentActualResult` / Reconciliation（VALID 或用户可见摘要）。

### 车程未开始

```text
前往 Landmannalaugar
建议预留 3 小时 36 分
基础车程 2 小时 46 分

[开始这段车程]
```

### 进行中（非导航页）

```text
这段车程已开始
开始时间 09:20

[记录中途停车]  [我到了]
```

不要：实时地图诱导、转向、偏航重算、剩余 ETA 刷新。

### 到达确认

```text
这段途中是否有不计入驾驶时间的停留？
· 没有
· 有，我来填写
· 不确定
```

### 到达后

```text
本段实际驾驶：3 小时 28 分
规划建议：3 小时 36 分
差异：少 8 分钟 / 本次预留多 8 分钟
```

---

## 用户侧不要展示

MAE、模型命中率、参数调整、Provider 误差归因（后台运营用）。

## 禁止话术（无冰岛 VALID Actual）

「根据真实数据校准」「比地图准 20%」「冰岛用户验证有效」「AI 精准预测车程」。
