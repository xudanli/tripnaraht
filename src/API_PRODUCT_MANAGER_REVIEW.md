## 🔄 三、接口调用流程

### 3.1 用户规划流程（统一）

```
用户注册/登录
  ↓
创建规划会话 (POST /api/agent/planning-assistant/sessions)
  ↓
发送规划消息 (POST /api/agent/planning-assistant/chat)
  ├─→ Exa MCP (Web搜索目的地信息)
  ├─→ Google Maps Direct (搜索地点)
  ├─→ Weather Direct API (查询天气)
  └─→ Hotel Direct API (搜索酒店)
  ↓
生成推荐和方案
  ↓
确认并保存行程 (POST /api/trips)
  ↓
添加行程项目 (POST /api/itinerary-items)
```

### 3.2 行程优化流程（统一）

```
获取行程详情 (GET /api/trips/:id)
  ↓
发送优化请求 (POST /api/agent/planning-assistant/chat，使用 tripId)
  ├─→ Google Maps Direct (计算路线、优化顺序)
  ├─→ Restaurant Direct API (搜索餐厅)
  └─→ Weather Direct API (查询天气)
  ↓
应用优化结果
  ↓
更新行程 (PUT /api/trips/:id)
```

**注意**: 行程优化现在统一使用规划助手接口，通过 `tripId` 参数指定要优化的行程。

### 3.3 MCP 能力调用流程

```
智能体接收用户请求
  ↓
分析意图和需求
  ↓
选择 MCP 服务
  ├─→ 检查服务可用性 (GET /api/mcp/capabilities/:serviceName/enabled)
  ├─→ 调用 MCP 工具
  └─→ 处理响应和错误
  ↓
整合结果并返回给用户
```
