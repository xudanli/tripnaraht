# Browserbase MCP 产品测试场景

## 📋 文档说明

本文档由产品经理和测试团队共同制定，涵盖 Browserbase MCP 在实际业务场景中的测试用例。

**测试目标**: 验证 Browserbase MCP 在 TripNara 平台中的实际应用场景

---

## 🎯 核心功能

Browserbase MCP 提供以下核心能力：
1. **浏览器会话管理** - 创建和管理浏览器会话
2. **页面导航** - 导航到指定 URL
3. **页面截图** - 捕获页面截图
4. **元素交互** - 点击页面元素
5. **JavaScript 执行** - 执行自定义 JavaScript 代码

## 🔧 测试用例详细设计

### 用例 1: 抓取 Booking.com 酒店价格

**前置条件**:
- Browserbase MCP 服务已配置
- OAuth 授权已完成

**测试数据**:
```json
{
  "url": "https://www.booking.com/hotel/example.html",
  "viewport": {
    "width": 1920,
    "height": 1080
  }
}
```

**测试步骤**:
1. 创建会话，访问酒店页面
2. 等待页面加载完成
3. 执行 JavaScript 提取价格信息：
   ```javascript
   const price = document.querySelector('.prco-val')?.textContent;
   const rating = document.querySelector('.bui-review-score__badge')?.textContent;
   return { price, rating };
   ```
4. 截图保存页面
5. 验证返回数据格式

**验证点**:
- ✅ 价格信息提取成功
- ✅ 评分信息提取成功
- ✅ 截图文件生成
- ✅ 数据格式正确

## 🚨 风险场景

### 高风险场景
1. **网站结构变化** - 选择器失效
2. **反爬虫机制** - IP 被封禁
3. **会话超时** - 长时间操作失败

### 应对措施
1. 使用更稳定的选择器策略
2. 实现重试机制
3. 监控会话状态
