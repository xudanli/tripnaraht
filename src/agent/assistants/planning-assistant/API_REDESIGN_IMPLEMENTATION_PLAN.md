async getRecommendations(
  @Query('q') naturalLanguage?: string,
  @Query() structuredParams?: RecommendationsQueryDto
) {
  // 如果提供了自然语言参数，使用AI提取参数
  if (naturalLanguage) {
    const extracted = await this.intentRecognizer.extractParams(naturalLanguage);
    return this.recommendationService.getRecommendations(extracted);

  return this.recommendationService.getRecommendations(structuredParams);
}

**关键实现**:
```typescript
@Post('chat')
async chat(@Body() dto: ChatRequestDto) {
  // 1. 意图识别
  const intent = await this.intentRecognizer.analyze(dto.message, dto.sessionId);
  
  // 2. 智能路由
  if (intent === 'RECOMMEND') {
    return this.recommendationService.getRecommendations({
      sessionId: dto.sessionId,
      naturalLanguage: dto.message,
    });
  } else if (intent === 'GENERATE_PLAN') {
    return this.planService.generatePlan({
      sessionId: dto.sessionId,
      naturalLanguage: dto.message,
    });
  }
  
  // 3. 通用对话处理
  return this.chatService.handleGeneralChat(dto);
}
```

## ⚠️ 风险管理和回滚方案

### 风险识别

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| 新接口性能问题 | 中 | 高 | 充分性能测试、限流控制 |
| AI能力退化 | 中 | 高 | 保持对话接口为主要入口 |
| 数据不一致 | 低 | 中 | 缓存失效策略、数据同步 |
| 用户迁移困难 | 中 | 中 | 充分文档、平滑迁移 |
| 技术债务积累 | 中 | 低 | 明确迁移计划、定期清理 |

### 回滚方案

#### 回滚触发条件

- 错误率 > 5%
- 响应时间 > 10秒（P95）
- 用户投诉 > 10起/天
- 严重bug影响核心功能

#### 回滚步骤

1. **立即回滚**（5分钟内）:
   - 使用功能开关关闭新接口
   - 前端切换回旧接口
   - 通知团队

2. **问题排查**（1小时内）:
   - 查看错误日志
   - 分析traceId
   - 定位问题根因

3. **修复和验证**（24小时内）:
   - 修复问题
   - 充分测试
   - 准备重新发布

4. **重新发布**（按灰度计划）:
   - 重新执行灰度发布流程
