- ✅ Restaurant Direct API：附近餐厅搜索
- ✅ Weather Direct API：实时天气查询

- ✅ Vision Service + OCR：图片识别地点、OCR提取文字（**新增，核心能力**）

### 4. 与现有系统集成评估

#### ✅ 集成点清晰

1. **与 Skills 系统集成**
   - MCP 能力通过 `McpClientService` 调用
   - 不影响现有 Skills 系统
   - 可以逐步迁移

2. **与多智能体系统集成**
   - 智能体通过 `AgentMcpManagerService` 获取能力配置
   - 不影响现有 Agent 架构
   - 可以逐步扩展

3. **与 LLM 服务集成**
   - MCP 能力作为工具调用
   - 不影响现有 LLM 服务
   - 可以逐步添加

#### ⚠️ 需要注意

1. **认证管理**
   - **问题**：多个 MCP 服务需要不同的认证方式（OAuth 2.0、API Key、JWT）
   - **建议**：统一认证管理服务，简化认证流程
   - **优先级**：P1

2. **错误处理统一**
   - **问题**：不同 MCP 服务的错误格式可能不同
   - **建议**：统一错误格式，简化错误处理
   - **优先级**：P1

### 5. 性能与成本优化建议

#### 性能优化

1. **缓存策略**
   - **建议**：为频繁调用的 MCP 服务添加缓存（如天气、汇率）
   - **缓存时间**：天气（1小时）、汇率（5分钟）、地点搜索（24小时）
   - **优先级**：P1

2. **批量调用**
   - **建议**：支持批量调用 MCP 服务（如批量搜索餐厅）
   - **优先级**：P2

3. **异步调用**
   - **建议**：非关键路径的 MCP 调用使用异步方式
   - **优先级**：P2

#### 成本优化

1. **调用频率控制**
   - **建议**：为每个 MCP 服务设置调用频率限制
   - **优先级**：P0（必须）

2. **降级策略**
   - **建议**：当 MCP 服务不可用时，使用备用服务或返回缓存结果
   - **优先级**：P0（必须）

3. **成本监控**
   - **建议**：实时监控 MCP 调用成本，设置告警阈值
   - **优先级**：P0（必须）
