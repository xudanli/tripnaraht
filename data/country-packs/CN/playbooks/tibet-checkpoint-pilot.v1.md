# 涉藏检查站试点 Playbook（v1）

> **免责**：本文是 TripNARA 中国经典自驾试点的**产品与编排操作说明**，不是法律意见，也不构成行政许可指引。检查站、边防与通行证件要求以当地主管部门**当日规定**为准；平台不代办审批、不保证可通行。

## 目标

让 G318 / G317 / G219 / 滇藏等涉藏廊道在「可编排、可提示、可出卡」时，把证件与检查站做成**可见硬提示**，避免静默假设全程畅通。

## 硬门禁

1. **证件自核**：身份证/护照、驾驶证、行驶证或租车合同等由用户自行准备并核验有效期。
2. **禁止代办暗示**：对话、知识卡、咨询话术不得暗示平台可代办进藏许可或绕过检查站。
3. **时间缓冲**：入藏与跨地区检查站预留排队时间，日里程勿排满理论值。

## 出发前检查清单

- 身份证件有效，姓名与租车/门票实名一致
- 自驾证照与保险凭证可出示（纸质或官方电子件）
- 涉外或特殊区域：自行确认是否需要额外通行许可；不确定则不要写入默认日程
- 车牌与车况正常；夜间抵达预留更长时间
- 配合检查，禁止冲卡；遇临时管控启用缓冲日
- 高反应先降程，再考虑赶路

## 产品规则（给编排/Agent）

| 规则 | 说明 |
|------|------|
| `checkpointLikely` | `wantsXizang=true` 时必须为 true |
| 合规卡 | `checkpoint_documents` 必须有可读文案（`contentUrl`） |
| 咨询 | 涉及检查站时附带免责声明，禁止「保证能过」 |
| G219 | 额外提示边境/管理区风险，非经验车队勿默认推荐 |

## 与合规知识卡关系

- 主卡：`checkpoint_documents`（涉藏检查站与证件）
- 连带：`high_altitude_pace`、`timed_entry_booking`

机器可读摘要见同目录 `tibet-checkpoint-pilot.v1.json`。
