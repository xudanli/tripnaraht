## Behavior

```text
ObservationAssessment (trip-impacting)
  → LookDecisionProblem (OPEN, detectedBy=USER)
  → linkedDecisionProblemId on assessment
  → PREVIEW CTA = decision:{problemId}  (Q2 #1 once problem exists)
  → constraintBridgeKey e.g. OFFICIAL_IS_FROAD_2WD
  → writesPlanVersion = false  (always)
```

| Semantic key | Preferred corridor (initial) | CTA after link |
|--------------|------------------------------|----------------|
| `RULE_TRIGGER.FROAD_VEHICLE_MISMATCH` | `repair:TERRAIN_F_ROAD_UNFIT` | `decision:{id}` |
| `WRONG_MEETING_POINT` | `navigation:meeting_point` | Decision/Nav |
| Image/location conflict | Decision pending | `decision:{id}` |

**No Apply.** Unsupported corridors return `unsupported:UNSUPPORTED_ACTION_CORRIDOR` (open RFC).
