## Behavior

```text

  → HeuristicExtractionProvider
  → Schema validate (fail → MODEL_FAILED / 422)
  → Forbidden language strip/reject
  → map → frozen Semantic Keys
  → Assessment (still no formal VehicleRoadFit BLOCK — S3/S4)
```

- No GPS + closed sign → `NOTICE` (not road `EXECUTION_BLOCK`)
- Low/missing critical fields → `requiredAdditionalViews` → RECAPTURE CTA
- Never infer 4WD from SUV appearance alone
- `writesPlanVersion = false`
