## Behavior

- PATCH merges day / location / tripContext / groundingHints / `confirmedIntent`
- Default on COMPLETED (and recoverable fails): **reassess** (extract → ground → assess); `reassess: false` merges only
- Feedback requires COMPLETED + matching `assessmentId`
- Both responses assert `writesPlanVersion: false`
- No Look Apply
