## 一、接口变更总览

### 1.1 新增字段（向后兼容）

以下字段为**新增字段**，前端可以忽略，不影响现有功能：

1. **`applySuggestion` 响应新增 `suggestionStatus` 字段**
2. **`chat` 响应中 `richContent` 支持推荐数据格式**

### 1.2 行为变更（需要前端适配）

1. **填充空闲时间场景**：响应格式变化，需要支持新的推荐数据结构
2. **接受建议场景**：响应包含 `suggestionStatus`，可用于更新UI状态

## 二、详细接口变更

### 2.1 应用建议接口 (`POST /trip-planner/apply-suggestion`)

#### 变更内容

**响应新增字段**（可选，向后兼容）：

```typescript
{
  success: true,
  message: string,
  item?: {...},
  tripUpdate?: {...},
  followUpSuggestions?: string[],
  // 🆕 新增字段
  suggestionStatus?: 'RESOLVED' | 'PENDING' | 'FAILED', // 建议状态
}
```

#### 前端处理建议

```typescript
// 示例：处理应用建议响应
const response = await applySuggestion(dto);

if (response.success) {
  // 如果返回 RESOLVED，可以更新UI，移除或标记建议为已解决
  if (response.suggestionStatus === 'RESOLVED') {
    // 更新建议列表，移除已解决的建议
    updateSuggestionStatus(response.suggestionId, 'RESOLVED');
    
    // 或者更新Abu的警告提示
    updateGuardianInsight(response.suggestionId, { status: 'resolved' });
  }
  
  // 更新行程项显示
  updateItineraryItem(response.item);
}
```

#### 测试用例

```typescript

  tripId: 'xxx',
  sessionId: 'xxx',
  suggestionId: 'abu_timing_001',

  suggestionType: 'modify_time', // 或 'timing'（会自动映射）
};

// 预期：result.suggestionStatus === 'RESOLVED'
// 预期：result.item.startTime 已更新

```

### 2.2 对话接口 (`POST /trip-planner/chat`)

#### 变更内容

**填充空闲时间场景的响应格式变更**：

**旧格式**（已废弃）：
```typescript
{
  message: "需要我帮您添加到行程中吗？",
  quickActions: [
    { id: '1', label: '✨ 自动填充推荐', action: 'AUTO_FILL' },
    { id: '2', label: '🎯 我来选择', action: 'MANUAL_SELECT' },
  ],
}
```

**新格式**（当前）：
```typescript
{
  message: "我为您找到了空闲时间段，并推荐了以下活动：...",
  intent: 'FILL_FREE_TIME',
  richContent: {
    type: 'poi_list',
    data: {
      recommendations: [
        {
          day: 1,
          timeSlot: { start: '12:00', end: '14:00' },
          duration: 120, // 分钟
          suggestions: [
            {
              id: 'rec_1_0_1234567890',
              name: '当地特色餐厅',
              type: 'RESTAURANT',
              reason: '午餐时间，体验地道美食',
              action: 'ADD_TO_ITINERARY', // 一键添加动作
            },
            // ... 更多推荐
          ],
        },
        // ... 更多时间段
      ],
      actionType: 'ADD_TO_ITINERARY',
    },
  },
  quickActions: [
    { id: '1', label: '🔄 刷新推荐', action: 'REFRESH_RECOMMENDATIONS' },
    { id: '2', label: '😌 保持空闲', action: 'KEEP_FREE' },
  ],
}
```

#### 前端处理建议

```typescript
// 示例：处理填充空闲时间响应
const response = await chat({
  tripId: 'xxx',
  message: '帮我填充空闲时间',
  sessionId: 'xxx',
});

if (response.intent === 'FILL_FREE_TIME' && response.richContent?.type === 'poi_list') {
  const recommendations = response.richContent.data.recommendations;
  
  // 渲染推荐列表
  recommendations.forEach(rec => {
    renderRecommendationCard({
      day: rec.day,
      timeSlot: rec.timeSlot,
      suggestions: rec.suggestions,
      onAddClick: (suggestionId) => {
        // 调用应用建议接口
        applySuggestion({
          tripId: 'xxx',
          sessionId: 'xxx',
          suggestionId: suggestionId,
          targetDay: rec.day,
          timeSlot: rec.timeSlot,
          suggestionType: rec.suggestions[0].type === 'RESTAURANT' 
            ? 'add_meal' 
            : 'add_place',
          place: {
            name: rec.suggestions[0].name,
            type: rec.suggestions[0].type,
          },
        });
      },
    });
  });
}
```

## 三、建议类型映射（前端可选）

### 3.1 Abu建议类型到操作类型映射

如果前端收到Abu的建议类型（如 `timing`、`early_start`），需要映射到 `applySuggestion` 的操作类型：

```typescript
// 前端映射表（可选，后端已自动映射）
const suggestionTypeMapping: Record<string, string> = {
  'timing': 'modify_time',
  'early_start': 'modify_time',
  'late_end': 'modify_time',
  'time_conflict': 'modify_time',
  'distance': 'optimize_route',
  'overlap': 'modify_time',
  'add_restaurant': 'add_meal',
  'add_activity': 'add_place',
};

// 使用示例
function mapSuggestionType(abuType: string): string {
  return suggestionTypeMapping[abuType] || abuType;
}

// 调用时
await applySuggestion({
  ...dto,
  suggestionType: mapSuggestionType(abuSuggestion.type), // 后端也会自动映射，这里是双重保险
});
```

**注意**：后端已实现自动映射，前端可以不实现此映射，直接传递Abu的建议类型即可。

## 四、UI更新建议

### 4.1 填充空闲时间场景

**UI变化**：
1. **不再显示**："需要我帮您添加到行程中吗？"的询问
2. **直接显示**：推荐活动列表，每个推荐有"一键添加"按钮
3. **交互优化**：点击"一键添加"后，立即调用 `applySuggestion`，无需再次确认

**UI组件建议**：

```tsx
// 推荐卡片组件
<RecommendationCard>
  <TimeSlot>第{day}天 {timeSlot.start}-{timeSlot.end}</TimeSlot>
  <RecommendationList>
    {suggestions.map(suggestion => (
      <RecommendationItem key={suggestion.id}>
        <Name>{suggestion.name}</Name>
        <Reason>{suggestion.reason}</Reason>
        <AddButton 
          onClick={() => handleAddToItinerary(suggestion)}
        >
          一键添加
        </AddButton>
      </RecommendationItem>
    ))}
  </RecommendationList>
</RecommendationCard>
```

### 4.2 接受建议场景

**UI变化**：
1. **状态更新**：点击"接受建议"后，如果返回 `suggestionStatus: 'RESOLVED'`，更新建议状态
2. **Abu警告更新**：将警告从"⚠️ 可能太早"更新为"✓ 已解决"或直接移除

**UI组件建议**：

```tsx
// Abu警告组件
<AbuWarning 
  suggestion={suggestion}
  onAccept={async () => {
    const result = await applySuggestion({
      ...dto,
      suggestionType: 'modify_time',
    });
    
    if (result.suggestionStatus === 'RESOLVED') {
      // 更新UI状态
      setSuggestionStatus('resolved');
      // 或者移除警告
      removeWarning(suggestion.id);
    }
  }}
/>
```

## 七、示例代码

### 7.1 完整的填充空闲时间流程

```typescript
// 1. 用户发送消息
const chatResponse = await chat({
  tripId: 'xxx',
  message: '帮我填充空闲时间',
  sessionId: 'xxx',
});

// 2. 解析推荐数据
if (chatResponse.richContent?.type === 'poi_list') {
  const recommendations = chatResponse.richContent.data.recommendations;
  
  // 3. 渲染推荐列表
  recommendations.forEach(rec => {
    rec.suggestions.forEach(suggestion => {
      // 4. 用户点击"一键添加"
      const addResult = await applySuggestion({
        tripId: 'xxx',
        sessionId: 'xxx',
        suggestionId: suggestion.id,
        targetDay: rec.day,
        timeSlot: rec.timeSlot,
        suggestionType: suggestion.type === 'RESTAURANT' ? 'add_meal' : 'add_place',
        place: {
          name: suggestion.name,
          category: suggestion.type,
        },
      });
      
      // 5. 更新UI
      if (addResult.success) {
        showSuccessMessage(`已添加「${suggestion.name}」到第${rec.day}天`);
        updateItinerary(addResult.item);
      }
    });
  });
}
```

### 7.2 完整的接受建议流程

```typescript
// 1. 用户看到Abu警告
const abuWarning = {
  id: 'abu_timing_001',
  message: '第1天01:00开始可能太早',
  suggestionType: 'timing', // 或 'early_start'
};

// 2. 用户点击"接受建议"
const result = await applySuggestion({
  tripId: 'xxx',
  sessionId: 'xxx',
  suggestionId: abuWarning.id,
  targetDay: 1,
  suggestionType: 'modify_time', // 或直接传 'timing'（后端会自动映射）
});

// 3. 检查结果
if (result.success && result.suggestionStatus === 'RESOLVED') {
  // 更新UI：移除警告或标记为已解决
  updateAbuWarning(abuWarning.id, { status: 'resolved' });
  
  // 更新行程项时间显示
  if (result.item) {
    updateItineraryItem(result.item);
  }
  
  showSuccessMessage(result.message);
}
```
