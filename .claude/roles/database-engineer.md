## 你必须理解的核心概念

### Prisma Schema

**定义**：Prisma Schema 是数据库结构的定义文件

**关键字段**：
- `model` - 数据模型定义
- `enum` - 枚举类型定义
- `relation` - 关系定义
- `index` - 索引定义

**参考文件**：
- `prisma/schema.prisma` - Prisma Schema 定义

### PostGIS 地理空间数据

**定义**：PostGIS 是 PostgreSQL 的地理空间扩展

**关键类型**：
- `geometry` - 几何类型
- `geography` - 地理类型
- `point` - 点类型
- `linestring` - 线类型
- `polygon` - 面类型

**关键函数**：
- `ST_Distance` - 计算距离
- `ST_Within` - 判断是否在范围内
- `ST_Intersects` - 判断是否相交
- `ST_Buffer` - 创建缓冲区

**参考文件**：
- `src/skills/geo/geo-find-nearby-poi.skill.ts` - 附近 POI 查找
- `src/skills/geo/geo-check-hazard-zones.skill.ts` - 危险区域检查

### 索引策略

**B-tree 索引**：
- 适用于等值查询和范围查询
- 适用于排序查询
- 适用于唯一约束

**GIN 索引**：
- 适用于数组类型
- 适用于全文搜索
- 适用于 JSONB 类型

**GiST 索引**：
- 适用于地理空间数据
- 适用于范围类型
- 适用于全文搜索

**SP-GiST 索引**：
- 适用于非平衡树结构
- 适用于某些特殊查询模式

### 查询性能优化

**关键指标**：
- 查询响应时间
- 索引命中率
- 数据库连接池使用率

**优化策略**：

- 使用读写分离（如需要）

## 常见问题

### Q1: 如何优化 PostGIS 查询性能？

**解决方案**：
1. 使用空间索引（GIST）
2. 使用 `ST_DWithin` 代替 `ST_Distance`
3. 使用 `ST_Intersects` 代替 `ST_Within`（如适用）
4. 限制查询范围（使用边界框）

### Q2: 如何优化 Prisma 查询性能？

**解决方案**：
1. 使用 `select` 只查询需要的字段
2. 使用 `include` 预加载关联数据
3. 使用 `where` 添加过滤条件
4. 使用索引优化查询
5. 使用连接池优化连接

### Q3: 如何设计数据迁移策略？

**解决方案**：
1. 使用 Prisma Migrate 进行迁移
2. 设计零停机迁移策略（如需要）
3. 设计数据回滚策略
4. 设计数据验证策略
5. 记录迁移日志
