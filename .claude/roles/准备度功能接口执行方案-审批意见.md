### 1.2 关键问题与建议

#### 问题 1：用户旅程与交互设计缺失 ⚠️

**问题描述**：
- 执行方案缺少用户进入准备度页面的完整旅程
- 缺少 AI 增强功能的交互设计（如何展示、如何开关、如何降级提示）
- 缺少用户反馈机制

**建议**：
1. **补充用户旅程**：
   ```
   用户进入准备度页面
     ↓
   加载基础准备度数据（确定性规则引擎）
     ↓
   检查 Feature Flag（是否启用 AI 增强）
     ↓
   如果启用：显示"AI 增强中..."加载状态
     ↓
   AI 增强完成：更新页面（个性化推荐、智能排序）
     ↓
   用户交互：勾选、查看修复方案、生成打包清单
     ↓
   用户反馈：对 AI 推荐进行反馈（有用/无用）
   ```

2. **补充交互设计**：
   - **AI 增强开关**：在页面右上角显示开关，默认关闭
   - **AI 增强标识**：AI 增强的内容显示"✨ AI 推荐"标识
   - **降级提示**：AI 增强失败时，显示"AI 增强暂时不可用，已为您显示基础结果"
   - **反馈机制**：每个 AI 推荐项旁边有"👍/👎"反馈按钮

3. **补充用户反馈收集**：
   - 埋点：`readiness_ai_feedback`（itemId, feedback, reason）
   - 用于持续优化 AI 推荐质量

**问题描述**：
- 执行方案提到了性能指标、成本指标，但缺少业务成功指标
- 缺少北极星指标和过程指标

**建议**：
1. **北极星指标**：
   - **准备度完成率**：用户完成所有必须项的比例（目标：> 80%）
   - **准备度页面停留时间**：用户平均停留时间（目标：> 3 分钟）

2. **过程指标**：
   - **AI 增强采用率**：启用 AI 增强的用户比例（目标：> 60%）
   - **AI 推荐点击率**：用户点击 AI 推荐项的比例（目标：> 40%）

#### 问题 3：功能边界不清晰 ⚠️

**问题描述**：
- AI 增强功能的边界不清晰（哪些场景必须用 AI，哪些场景不能用）
- 异常处理场景不完整（用户拒绝 AI 推荐、AI 推荐错误等）

**建议**：
1. **明确功能边界**：
   - **必须使用规则引擎**：核心检查项（blocker、must、should、optional）
   - **可以使用 AI 增强**：个性化排序、截止日期推断、办理渠道推荐、推荐原因生成
   - **禁止使用 AI**：生成核心检查项、修改检查项内容、生成证据引用

2. **补充异常处理场景**：
   - **用户拒绝 AI 推荐**：记录拒绝原因，用于优化模型
   - **AI 推荐错误**：用户反馈"无用"时，记录错误类型，用于模型训练
   - **AI 增强失败**：降级到基础功能，不影响核心流程
   - **用户关闭 AI 增强**：保存用户偏好，后续不再显示 AI 增强

**问题描述**：

- 缺少重试机制、超时处理、部分失败处理等细节

**建议**：
1. **补充错误处理逻辑**：
   ```typescript
   // 错误处理策略
   try {
     // 主模型调用
     result = await claudeService.generate(...);
   } catch (error) {
     // 错误分类
     if (error.type === 'TIMEOUT') {
       // 超时：降级到 DeepSeek
       result = await deepseekService.generate(...);
     } else if (error.type === 'RATE_LIMIT') {
       // 限流：等待后重试
       await sleep(1000);
       result = await claudeService.generate(...);
     } else if (error.type === 'SCHEMA_VALIDATION') {
       // Schema 验证失败：重试 2 次
       for (let i = 0; i < 2; i++) {
         try {
           result = await claudeService.generate(...);
           break;
         } catch (retryError) {
           if (i === 1) {
             // 最后一次重试失败：降级到基础功能
             return baseResult;
           }
         }
       }
     } else {
       // 其他错误：降级到基础功能
       return baseResult;
     }
   }
   ```

2. **补充部分失败处理**：
   - 如果个性化清单 AI 增强失败，但风险预警 AI 增强成功，应该返回部分增强结果
   - 不应该因为一个功能失败就全部降级
