## 📋 一、执行摘要

### 1.1 方案目标

**核心目标**：
- ✅ **保持确定性架构**：准备度检查必须基于规则引擎，确保决策的确定性和可追溯性
- ⚠️ **增强个性化体验**：在保持确定性的基础上，通过 AI 增强提供个性化推荐
- 💰 **控制成本与性能**：通过智能缓存、批量处理、降级策略控制 AI 增强成本
- 🔬 **建立评估体系**：通过 A/B 测试和性能监控持续优化

### 1.2 关键约束

**硬约束**：
- **决策优先原则**：准备度检查必须是确定性的，不能依赖 LLM 生成核心检查项
- **证据链要求**：所有 AI 增强的输出必须关联证据来源，支持可解释性
- **系统可退化**：AI 增强功能失败时，必须降级到基础功能，不能影响核心流程
- **成本控制**：单次请求 AI 增强成本 < $0.05，总成本增长 < 20%

**软约束**：
- **性能要求**：AI 增强后总延迟 < 4s（P95）
- **用户体验**：AI 增强功能必须可开关，用户可选择是否启用

### 2.2 核心设计原则

#### 2.2.1 确定性优先（Deterministic First）

**原则**：准备度检查的核心逻辑必须基于规则引擎，确保确定性。

**架构体现**：
```typescript
// ✅ 正确：核心检查基于规则引擎
const baseResult = await readinessService.checkFromDestination(
  destinationId,
  context
);

// ✅ 正确：AI 增强是可选的，不影响核心结果
if (enableAIEnhancement) {
  const enhancedResult = await aiService.enhance(baseResult, userProfile);
  return enhancedResult;
}
return baseResult;
```

**约束**：
- **核心检查项**（blocker、must、should、optional）必须来自规则引擎
- **AI 增强**只能用于个性化排序、推荐原因、截止日期推断等辅助功能
- **AI 增强失败**时，必须返回基础结果，不能阻塞核心流程

---

#### 2.2.2 可退化设计（Graceful Degradation）

**原则**：AI 增强功能必须可降级，确保系统稳定性。

**架构体现**：
```typescript
// 降级策略
try {
  // 尝试 AI 增强
  const enhanced = await aiService.enhance(...);
  return enhanced;
} catch (error) {
  // AI 增强失败，降级到基础功能
  this.logger.warn('AI enhancement failed, falling back to base result', error);
  return baseResult;
}
```

**降级路径**：
1. **主模型失败** → 降级到 DeepSeek
2. **DeepSeek 失败** → 降级到基础功能（无 AI 增强）
3. **RAG 失败** → 使用静态数据源
4. **缓存失败** → 直接调用服务（性能下降但功能可用）

---

#### 2.2.3 证据链支持（Evidence Chain）

**原则**：所有 AI 增强的输出必须关联证据来源。

**架构体现**：
```typescript
interface AIEnhancedItem {
  // 基础数据（来自规则引擎）
  baseItem: ReadinessFindingItem;
  
  // AI 增强数据
  aiEnhancements: {
    deadline?: {
      value: string;
      evidence: string[]; // 证据来源
      confidence: number; // 置信度
    };
    channel?: {
      value: string;
      evidence: string[]; // 证据来源
      confidence: number;
    };
    personalizedRank?: {
      value: number;
      reasoning: string; // 推理过程
      evidence: string[]; // 证据来源
    };
  };
}
```

**证据来源**：
- **规则引擎输出**：确定性证据
- **RAG 检索结果**：知识库证据
- **LLM 推理过程**：推理链证据

### 4.1 AI 增强服务实现

#### 4.1.1 ReadinessAIService 实现

**文件位置**：`src/trips/readiness/services/readiness-ai.service.ts`

**核心方法**：
```typescript
@Injectable()
export class ReadinessAIService {
  constructor(
    private readonly llmService: LLMService,
    private readonly ragService: RAGService,
    private readonly cacheService: ReadinessCacheService,
    private readonly logger: Logger,
  ) {}

  /**
   * 增强个性化清单
   */
  async enhancePersonalizedChecklist(
    baseResult: ReadinessCheckResult,
    userProfile: UserProfile,
    tripContext: TripContext,
    options: { enableAI: boolean } = { enableAI: true },
  ): Promise<AIEnhancedReadinessResult> {
    // 1. 检查 Feature Flag
    if (!options.enableAI) {
      return this.toBaseResult(baseResult);
    }

    // 2. 检查缓存
    const cacheKey = this.generateCacheKey('checklist', baseResult, userProfile);
    const cached = await this.cacheService.get(cacheKey);
    if (cached) {
      return cached;
    }

    // 3. AI 增强（带降级）
    try {
      const enhanced = await this.enhanceWithAI(baseResult, userProfile, tripContext);
      
      // 4. 缓存结果
      await this.cacheService.set(cacheKey, enhanced, { ttl: 24 * 60 * 60 }); // 24小时
      
      return enhanced;
    } catch (error) {
      this.logger.warn('AI enhancement failed, falling back to base result', error);
      return this.toBaseResult(baseResult);
    }
  }

  /**
   * 使用 AI 增强（内部方法）
   */
  private async enhanceWithAI(
    baseResult: ReadinessCheckResult,
    userProfile: UserProfile,
    tripContext: TripContext,
  ): Promise<AIEnhancedReadinessResult> {
    // 并行调用多个 AI 增强功能
    const [deadlines, channels, rankings] = await Promise.all([
      this.inferTaskDeadlines(baseResult, tripContext),
      this.retrieveChannels(baseResult, userProfile),
      this.rankByUserProfile(baseResult, userProfile),
    ]);

    return {
      ...baseResult,
      aiEnhancements: {
        deadlines,
        channels,
        rankings,
      },
    };
  }

  /**
   * 推断任务截止日期
   */
  private async inferTaskDeadlines(
    result: ReadinessCheckResult,
    tripContext: TripContext,
  ): Promise<DeadlineEnhancement[]> {
    const prompt = this.buildDeadlinePrompt(result, tripContext);
    
    try {
      const response = await this.llmService.generate({
        model: 'claude-3-5-sonnet',
        prompt,
        schema: DeadlineEnhancementSchema,
        temperature: 0.3, // 低温度确保确定性
      });

      return response.data;
    } catch (error) {
      // 降级到 DeepSeek
      try {
        const response = await this.llmService.generate({
          model: 'deepseek',
          prompt,
          schema: DeadlineEnhancementSchema,
          temperature: 0.3,
        });
        return response.data;
      } catch (fallbackError) {
        this.logger.error('All LLM providers failed for deadline inference', fallbackError);
        return []; // 返回空数组，不影响基础功能
      }
    }
  }

  // ... 其他方法
}
```

#### 4.1.2 缓存服务实现

**文件位置**：`src/trips/readiness/services/readiness-cache.service.ts`

**核心方法**：
```typescript
@Injectable()
export class ReadinessCacheService {
  constructor(
    private readonly redis: Redis,
    private readonly memoryCache: Map<string, CacheEntry>, // L1 缓存
    private readonly logger: Logger,
  ) {}

  /**
   * 获取缓存（分层查找）
   */
  async get<T>(key: string): Promise<T | null> {
    // L1: 内存缓存（5分钟）
    const l1Entry = this.memoryCache.get(key);
    if (l1Entry && Date.now() - l1Entry.timestamp < 5 * 60 * 1000) {
      return l1Entry.data as T;
    }

    // L2: Redis 缓存（24小时）
    try {
      const l2Data = await this.redis.get(key);
      if (l2Data) {
        const parsed = JSON.parse(l2Data);
        // 回填 L1 缓存
        this.memoryCache.set(key, {
          data: parsed,
          timestamp: Date.now(),
        });
        return parsed as T;
      }
    } catch (error) {
      this.logger.warn('Redis cache get failed', error);
    }

    // L3: 数据库缓存（7天）- 可选实现
    // ...

    return null;
  }

  /**
   * 设置缓存（分层存储）
   */
  async set<T>(key: string, data: T, options: { ttl?: number } = {}): Promise<void> {
    const ttl = options.ttl || 24 * 60 * 60; // 默认 24 小时

    // L1: 内存缓存
    this.memoryCache.set(key, {
      data,
      timestamp: Date.now(),
    });

    // L2: Redis 缓存
    try {
      await this.redis.setex(key, ttl, JSON.stringify(data));
    } catch (error) {
      this.logger.warn('Redis cache set failed', error);
    }
  }

  /**
   * 生成缓存键
   */
  generateCacheKey(
    type: string,
    baseResult: ReadinessCheckResult,
    userProfile: UserProfile,
  ): string {
    const hash = createHash('sha256')
      .update(JSON.stringify({
        type,
        tripId: baseResult.tripId,
        userProfileHash: this.hashUserProfile(userProfile),
        resultHash: this.hashResult(baseResult),
      }))
      .digest('hex');
    
    return `readiness:${type}:${hash}`;
  }
}
```

@Injectable()
export class ReadinessFeatureFlagsService {
  constructor(
    private readonly prisma: PrismaService,
    private readonly configService: ConfigService,

  /**
   * 检查是否启用 AI 增强
   */
  async isAIEnhancementEnabled(
    userId?: string,
    feature: string = 'readiness_ai_enhancement',
  ): Promise<boolean> {
    // 1. 全局开关（环境变量）
    const globalFlag = this.configService.get<boolean>(`FEATURE_FLAG_${feature}`);
    if (globalFlag === false) {
      return false;
    }

    // 2. 用户级别开关（数据库）
    if (userId) {
      const userFlag = await this.prisma.userFeatureFlag.findUnique({
        where: { userId_feature: { userId, feature } },
      });
      if (userFlag?.enabled === false) {
        return false;
      }
      if (userFlag?.enabled === true) {
        return true;
      }
    }

    // 3. 默认值（配置）
    return this.configService.get<boolean>(`FEATURE_FLAG_${feature}_DEFAULT`, false);
  }
}
