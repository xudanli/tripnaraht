```typescript

}
```

- ✅ 前端可以根据需要选择使用哪种格式

**实现逻辑**：
```typescript
// 如果有结构化问题，自动生成简单字符串格式
if (state.clarification_questions && state.clarification_questions.length > 0) {
  result.clarificationQuestions = state.clarification_questions;
  result.clarificationMessage = this.formatClarificationMessage(state.clarification_questions);
}
```
