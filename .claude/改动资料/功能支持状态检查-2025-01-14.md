### 2. 扩展 inputSchema 功能

#### ❌ 未支持

- **支持更复杂的验证规则（类型检查、范围检查等）**

**当前 `SkillInputSchema` 接口**：
```typescript
export interface SkillInputSchema {
  /** 必需参数列表 */
  required?: string[];
  /** 参数依赖关系：参数之间的依赖和替代关系 */
  dependencies?: Array<{
    param: string;
    alternatives?: string[];
  }>;
  /** 参数提取器：从 context/request 中提取参数 */
  extractors?: Record<string, string>;
}
```

**缺失的功能**：
- ❌ 类型检查（如 `string`、`number`、`array`、`object`）
- ❌ 范围检查（如 `min`、`max`、`minLength`、`maxLength`）
- ❌ 格式验证（如 `email`、`url`、`date`）
- ❌ 枚举值检查（如 `enum: ['option1', 'option2']`）
- ❌ 自定义验证函数

**示例（当前不支持）**：
```typescript
inputSchema: {
  required: ['age'],
  typeChecks: {
    age: { type: 'number', min: 0, max: 120 },
    email: { type: 'string', format: 'email' },
    tags: { type: 'array', minLength: 1, maxLength: 10 },
  },
}
```

---

#### ❌ 未支持

- **支持从前面步骤的结果中提取参数**

**当前提取器支持**：
- ✅ 从 `context` 中提取（如 `context.tripId`）
- ✅ 从 `request` 中提取（如 `request.trip_id`、`request.message`）
- ❌ **不支持**：从前面步骤的结果中提取（如 `step1.result.itinerary`）

**当前 `extractors` 定义**：
```typescript
extractors?: Record<string, string>; // 提取器名称，如 'tripId', 'countryCode'
```

**缺失的功能**：
- ❌ 从步骤结果中提取（如 `fromStep: 'step1', path: 'result.itinerary'`）
- ❌ 从多个步骤结果中合并提取
- ❌ 条件提取（如：如果 step1 成功，则从 step1.result 提取）

**示例（当前不支持）**：
```typescript
inputSchema: {
  extractors: {
    itinerary: {
      fromStep: 'itinerary.generate',
      path: 'result.itinerary',
    },
    adjustments: {
      fromStep: 'itinerary.verify',
      path: 'result.issues',
    },
  },
}
```

### 3. 自动生成验证规则

#### ❌ 未支持

- **从 TypeScript 接口自动生成 `inputSchema`**

**当前状态**：
- ❌ 没有自动生成工具
- ❌ 没有从 TypeScript 接口提取验证规则的功能
- ❌ 需要手动为每个 skill 定义 `inputSchema`

**缺失的功能**：
- ❌ 从 TypeScript 接口定义自动提取必需参数
- ❌ 从 TypeScript 类型信息自动生成类型检查规则
- ❌ 从 JSDoc 注释自动提取验证规则
- ❌ 自动生成 `inputSchema` 的工具或脚本

**示例（当前不支持）**：
```typescript
// 从接口定义自动生成
export interface MySkillInput extends SkillInput {
  /** @required */
  name: string;
  /** @min 0 @max 100 */
  age: number;
  /** @optional */
  email?: string;
}

// 自动生成 inputSchema:
// {
//   required: ['name', 'age'],
//   typeChecks: {
//     name: { type: 'string' },
//     age: { type: 'number', min: 0, max: 100 },
//   },
// }
```
