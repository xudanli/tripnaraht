**实施日期**: 2025-01-14

## ✅ 已添加的验证规则

### 新增验证规则

1. **`itinerary.generate`**
   - 必需参数：`request` (TripPlanRequest)
   - 说明：通常由 LLM 在 plan 编排时提供

2. **`itinerary.verify`**
   - 必需参数：`itinerary` (Itinerary)
   - 说明：通常来自前面步骤（`itinerary.generate`）的结果

3. **`transport.search`**
   - 必需参数：`origin`, `destination`
   - 说明：起点和终点都是必需的

4. **`poi.search`**
   - 必需参数：`query`
   - 说明：搜索关键词是必需的

5. **`readiness.generateChecklist`**
   - 必需参数：`world` 或 `tripId`
   - 说明：需要世界模型上下文或行程 ID

6. **`opening_hours.get`**
   - 必需参数：`poi_ids` (string[])
   - 说明：POI ID 数组，通常由 LLM 在 plan 编排时提供，或来自前面步骤的结果

7. **`repair.apply`**
   - 必需参数：`itinerary` (Itinerary), `adjustments` (RequiredAdjustment[])
   - 说明：`itinerary` 通常来自前面步骤（`itinerary.generate`）的结果，`adjustments` 通常来自前面步骤（`itinerary.verify`）的结果

8. **`plan.gate.runThreeGuardians`**
   - 必需参数：`planState` (PlanState)
   - 可选参数：`tripId`（如果 `planState.world` 不存在，需要 `tripId` 来构建 world）
   - 说明：用于对方案进行完整评审

9. **`plan.gate.precheck`**
   - 必需参数：`planState` (PlanState)
   - 说明：快速门控检查（数据足够时做硬判断，数据不足时标记需确认）

10. **`plan.architect.generateSkeleton`**
    - 必需参数：`context` (PlanContext)
    - 可选参数：`tripId`, `world`（如果需要构建世界模型，需要 `tripId`）
    - 说明：从目标与约束生成 2-3 套行程骨架方案

11. **`plan.budget.estimateBaseline`**
    - 必需参数：`planState` (PlanState), `destination` ({ country?: string; city?: string })
    - 说明：快速给出预算拆分与区间估算

## 📋 验证规则详情

### itinerary.generate

```typescript
'itinerary.generate': {
  dependencies: [
    { param: 'request' }, // 必需参数：TripPlanRequest
  ],
  // request 通常由 LLM 在 plan 编排时提供，这里只做基本检查
},
```

**验证逻辑**：
- 检查 `input.request` 是否存在
- 如果不存在，标记为缺失参数

### itinerary.verify

```typescript
'itinerary.verify': {
  dependencies: [
    { param: 'itinerary' }, // 必需参数：Itinerary
  ],
  // itinerary 通常来自前面步骤（itinerary.generate）的结果
},
```

**验证逻辑**：
- 检查 `input.itinerary` 是否存在
- 如果不存在，标记为缺失参数
- 注意：如果 `itinerary` 来自前面步骤的结果，验证时可能无法检测到（需要在 plan 验证阶段检查）

### transport.search

```typescript
'transport.search': {
  dependencies: [
    { param: 'origin' }, // 必需参数
    { param: 'destination' }, // 必需参数
  ],
},
```

**验证逻辑**：
- 检查 `input.origin` 是否存在
- 检查 `input.destination` 是否存在
- 如果任一缺失，标记为缺失参数

### poi.search

```typescript
'poi.search': {
  dependencies: [
    { param: 'query' }, // 必需参数：搜索关键词
  ],
  // query 通常由 LLM 在 plan 编排时提供
},
```

**验证逻辑**：
- 检查 `input.query` 是否存在
- 如果不存在，标记为缺失参数

### readiness.generateChecklist

```typescript
'readiness.generateChecklist': {
  dependencies: [
    { param: 'world', alternatives: ['tripId'] }, // 需要 world 或 tripId
    { param: 'tripId', alternatives: ['world'] },
  ],
  extractors: {
    tripId: (context, request) => context.tripId || request.trip_id,
  },
},
```

**验证逻辑**：
- 检查 `input.world` 或 `input.tripId` 是否存在
- 如果都不存在，尝试从 context/request 中提取 `tripId`
- 如果仍然不存在，标记为缺失参数
