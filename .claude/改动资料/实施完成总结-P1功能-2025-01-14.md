## 🎯 任务2：信任建立机制（AI能力展示）

### 实施内容

**文件**：
- `src/agent/interfaces/trip-plan.interface.ts`：新增 `AICapabilityDisplay` 接口
- `src/agent/dto/route-and-run.dto.ts`：在 `explain` 字段中添加 `ai_capability_display`
- `src/agent/services/agent.service.ts`：实现 `generateAICapabilityDisplay` 方法

**新增接口**：
```typescript
export interface AICapabilityDisplay {
  /** 本次请求的成功状态 */
  success: boolean;
  
  /** 使用的AI能力 */
  capabilities_used: Array<{
    name: string;
    description: string;
    status: 'SUCCESS' | 'PARTIAL' | 'FAILED';
  }>;
  
  /** 数据质量指标 */
  data_quality: {
    completeness: number; // 0-1，数据完整性
    freshness: number; // 0-1，数据新鲜度
    reliability: number; // 0-1，数据可靠性
  };
  
  /** 决策置信度 */
  confidence: {
    overall: number; // 0-1，整体置信度
    gate_evaluation: number; // 0-1，Gate评估置信度
    plan_generation: number; // 0-1，行程生成置信度
  };
  
  /** 局限性说明（提升信任） */
  limitations?: Array<{
    type: 'DATA_MISSING' | 'SERVICE_UNAVAILABLE' | 'UNCERTAINTY' | 'ASSUMPTION';
    description: string;
    impact: 'LOW' | 'MEDIUM' | 'HIGH';
  }>;
}
```

**实现逻辑**：
1. 从决策日志中提取使用的AI能力（技能）
2. 计算数据质量指标（完整性、新鲜度、可靠性）
3. 计算决策置信度（整体、Gate评估、行程生成）
4. 识别并说明局限性（数据缺失、不确定性等）

**关键特性**：
- ✅ 透明化AI能力使用情况
- ✅ 展示数据质量，建立用户信任
- ✅ 明确说明局限性，避免过度承诺
- ✅ 提供置信度指标，帮助用户理解决策可靠性

### 验收标准

- ✅ 响应中包含 `ai_capability_display` 字段
- ✅ AI能力展示包含使用的技能和状态
- ✅ 数据质量指标计算准确
- ✅ 决策置信度计算合理
- ✅ 局限性说明清晰，帮助用户理解
